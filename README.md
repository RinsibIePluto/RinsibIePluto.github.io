# Cyrune website

These files are the developer website for Google Play and AdMob. Copy everything in this folder
(including `.nojekyll`) to the root of the public repo `RinsibIePluto.github.io`, then turn on
GitHub Pages for it (Settings → Pages → Deploy from a branch → main, / root).

| File | Public URL | Used for |
| --- | --- | --- |
| index.html | https://rinsibiepluto.github.io/ | Developer website on the Play listing |
| cyrune/privacy.html | https://rinsibiepluto.github.io/cyrune/privacy.html | Privacy policy link in Play Console |
| cyrune/terms.html | https://rinsibiepluto.github.io/cyrune/terms.html | Terms of service link (trader status) |
| play/ | https://rinsibiepluto.github.io/play/ | The game in the browser (built by `python3 build-web.py`) |
| app-ads.txt | https://rinsibiepluto.github.io/app-ads.txt | AdMob seller verification |
