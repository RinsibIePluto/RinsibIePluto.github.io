Beaufort cipher

The Beaufort cipher looks like the Vigenère cipher, but it works backwards: each cipher letter is the key letter minus the message letter. That small change makes it reciprocal, so the same key and the same step both lock and unlock a message.

Difficulty in Cyrune: ★★★★☆

A little history

The cipher is named after Sir Francis Beaufort, the Royal Navy hydrographer best known for the Beaufort wind scale. Its reciprocal design made it practical for machines, because one setting both encrypts and decrypts. The US Army's M-209, a hand-cranked cipher machine used in the field in the Second World War, was built on the same principle.

How it works

  1. Choose a keyword, for example KEY, and repeat it under the message.
  2. For each letter, take the key letter's number minus the message letter's number (A = 0 … Z = 25).
  3. If the result is negative, add 26.

How to crack it

Beaufort falls to the same attack as Vigenère: find the keyword length from repeated patterns, split the text into columns, and solve each column. Each column is a reversed alphabet with a shift, so letter counting still works once you know the trick.

Beaufort in Cyrune

Cyrune's Beaufort key has three letters, used in turn, so letters 1 and 4 share a key letter, as do 2 and 5. For any green tile, add the green letter to the lamp above it (A = 0, wrapping at 26) and you have that key letter, which also unlocks the letter three places along.
