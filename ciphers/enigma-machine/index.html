Enigma machine

Enigma was the German cipher machine of the Second World War. Its rotors turned with every key press, so the same letter encrypted differently each time. Breaking it took some of the greatest codebreaking work in history.

Difficulty in Cyrune: ★★★★★

A little history

The German engineer Arthur Scherbius patented the first Enigma in 1918 as a machine for businesses, and the German armed forces adopted it in the 1920s and 1930s. Polish mathematicians, led by Marian Rejewski, first broke it in 1932 and shared their work with Britain and France weeks before the war began. At Bletchley Park, Alan Turing, Gordon Welchman and thousands of colleagues built on it, using electromechanical machines called bombes to search for each day's settings.

How it works

  1. Pressing a key sends an electric current through three rotors, each wired to scramble the alphabet.
  2. A reflector sends the current back through the rotors by a different path, lighting a lamp: the cipher letter.
  3. Before each letter, the right-hand rotor turns one step; every 26 steps it nudges the next rotor along, like a mileometer.

Because the rotors move with every letter, the same letter encrypts differently each time:

Real military Enigmas added a plugboard that swapped pairs of letters, and operators chose three rotors from a set of five and set rings on each. Together that gave about 159 quintillion possible settings.

How it was broken

Enigma had a flaw built into its reflector: a letter could never encrypt to itself. Codebreakers used likely words, called cribs, such as weather reports or routine phrases: if a crib's letter ever lined up with the same cipher letter, that position was impossible. The bombes raced through rotor settings, rejecting every one that contradicted the crib, until only a handful were left to test by hand.

Enigma in Cyrune

Cyrune runs a working Enigma I with rotors I-II-III and reflector B, without the plugboard. The key is the three starting rotor letters: 17,576 options. Use the real codebreakers' trick: tap a window to pin a letter you suspect (green tiles pin themselves), then press Run bombe. It tests every rotor setting and lists the stops that fit; two pins usually leave a few dozen to read through.
