Run-on Morse

Morse code turns each letter into a pattern of short and long signals, dots and dashes. Normally a pause marks where each letter ends. Take the pauses away and you get run-on Morse, which can be read in many different ways.

Difficulty in Cyrune: ★★★☆☆

A little history

Samuel Morse and his partner Alfred Vail developed the code for the electric telegraph in the 1830s and 1840s. The first public message on the line between Washington and Baltimore, in 1844, was "What hath God wrought". Vail is said to have counted the letters in a printer's box of type to find the most common ones, which is why E is a single dot and T a single dash. The international version that's still used by radio amateurs today was standardised later in the 1800s.

Strictly speaking, Morse is a code, not a cipher: it isn't secret, it's just a different way of writing letters. The puzzle comes from losing the gaps.

How it works

Each letter has its own pattern, from one signal (E is ·) to four (Q is ––·–). When people send Morse, they leave a short pause between letters and a longer one between words.

Why run-on Morse is hard

Without the gaps, one stream of dots and dashes can be split into letters in many ways. Six dots in a row, ······, could be HI, IH, SS, III or six E's, and every one of those is valid Morse. The only way to decide is to find the split that makes a real word.

How to crack it

Work from the ends inward: try the first one to four signals as a letter, and see whether the rest of the stream can still be split into a sensible word. Long runs of the same signal are useful landmarks, because a dash dash dash (O) or a run of dots (S, H) has fewer ways to break. And if you know the word length, as you do in Cyrune, that rules out most splits.

Morse in Cyrune
