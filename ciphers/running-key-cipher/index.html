Running key

A running key cipher is a Vigenère cipher whose key never repeats: it's as long as the message itself, usually taken from a book that both sides own.

Difficulty in Cyrune: ★★★★★

A little history

A repeating keyword was the Vigenère cipher's weakness, so the obvious fix was a key that doesn't repeat. Spies and diplomats took their keys from an agreed page of an agreed book. In 1918 the American cryptologist William Friedman, one of the founders of modern codebreaking, showed how running keys could still be broken, because the key was ordinary language too.

How it works

  1. Agree on a key text, at least as long as the message.
  2. Shift each message letter by the key letter in the same position (A = 0 … Z = 25).

How to crack it

Friedman's insight was that both the message and the key are English, and English is very predictable. Pairs of common letters (E with T, A with O) produce the cipher letters far more often than pairs of rare ones. So a codebreaker can guess a common word in one text, see what it implies for the other, and keep the guesses that make sense in both. If the key were truly random letters, used only once, this would be impossible: that's the one-time pad, the only cipher proven unbreakable.

Running key in Cyrune

Cyrune's running key is another five-letter word, so you're solving two words at once. Type a letter in either row, the key boxes or the message windows, and the other row fills in. If the key turns into something unlikely, like Q or X, think again; common letters (E, A, R, T) are good guesses for either word.
